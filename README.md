# Домашние задания по ОРИС

| ДЗ | Содержание |
| --- | --- |
| [Homework_1](Homework_1/) | **HTML и CSS.** Страница поиска SearcherFinder и справочник HTMLKnowledge. |
| [Homework_2](Homework_2/) | **HTTP-сервер на C#.** `HttpListener` непрерывно принимает запросы по адресу из `settings.json` и отдаёт страницу поиска. |
| [Homework_3](Homework_3/) | **Статические файлы.** Сервер отдаёт SearcherFinder и HTMLKnowledge, выставляет HTTP-заголовки и MIME-типы и возвращает страницу ошибки 404. |
| [Homework_4](Homework_4/) | **Цепочка обработчиков.** Паттерн Chain of Responsibility для раздачи файлов, вызова контроллеров и обработки 404. |
| [Homework_5](Homework_5/) | **Маршрутизация и почта.** Атрибуты контроллеров, параметры из Query и HTML-форм. Тестовое письмо сохраняется в `.eml` или отправляется через SMTP. |
| [Homework_6](Homework_6/) | **HTTP-результаты.** `BaseController`, интерфейс `IHttpResult` и ответы `HtmlResult` и `JsonResult`. |
| [Homework_7](Homework_7/) | **Библиотеки и шаблоны.** HTTP-фреймворк и HTML-шаблонизатор вынесены в библиотеки. В шаблонах работают подстановки, условия и циклы. |
| [Homework_8](Homework_8/) | **MSTest.** Тесты маршрутизации, раздачи статики, форматов ответа и HTML-шаблонизатора. |
| [Homework_9](Homework_9/) | **Мини-ORM.** CRUD для PostgreSQL через ADO.NET и Npgsql, параметризованный SQL и тесты. |
| [Homework_10](Homework_10/) | **Вход и сеансы.** Аутентификация с cookie, выход из аккаунта, защита маршрутов через `[Authorize]` и тесты. |
